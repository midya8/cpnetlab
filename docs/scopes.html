WITHDRAW A STATEMENT, NOT AN OUTCOME

One row can
govern many flips.

Withdrawing a conditional row removes every improving edge justified by that row. It does not reverse the preference, make the values indifferent, remove any outcomes or change the original supplied model.

These are counterfactual constraint graphs, not complete CP-nets after withdrawal, automatic recommendations or extended partial-model semantics. A path is reported even in an inconsistent graph, without calling it an entailed strict preference.

Python builds edges by complete conditional rows and uses breadth-first paths and immediate-subset tests. The independent checker rebuilds row edges from Hamming-one outcome pairs, uses Floyd-Warshall distances, and compares all proper subsets. It verifies every graph record and every antichain, not just displayed examples. JavaScript uses the base engine's validation and improving graph; it is not a separate verifier.
