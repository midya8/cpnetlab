TWO GRAPHS, TWO QUESTIONS

A dependency cycle
need not be a preference cycle.

Parent dependencies say which conditional row applies. Improving-outcome edges say which single flip is preferred, all else equal. Only a cycle of improving outcomes blocks every strict ranking.

For an inconsistent model we show the actual cycle and zero compatible rankings. We do not turn inconsistency into a vacuous claim that every outcome is preferred.

Different construction, independent checking

Python generates edges by conditional rows and uses breadth-first paths and prefix-ideal ranking counts. The independent checker instead compares all Hamming-one outcome pairs, uses Floyd-Warshall distances and suffix-removal ranking counts. It reconstructs the entire report, including every path and ranking witness, without importing the generator.

Shared input validation is disclosed. Browser JSON earns independent verification only after cpnetlab verify evidence.json accepts it. A click or export is not that check.
